4. 报告 commit 与 project HEAD 一致，打印 COMMIT_MATCH。
5. patch 生成 candidate.patch、patch-plan.json，风格为 direct，只在 main.o 依赖行增加 config.h，保留 unused.h 和配方。
6. git apply --check 成功，打印 APPLY_CHECK_PASS_SOURCE_CLEAN；原 Makefile 没有应用候选。
7. 将报告副本 commit 置为 40 个 0 后，patch 以 STALE_REPORT 拒绝；打印 SOURCE_BYTES_UNCHANGED，保存 expected-failure.json。
8. 原样例 git status --short 无输出，保存结论.txt。7 份容器日志均以 STEP_EXIT_CODE=0 结束；过期报告检查重复一次，保留两份日志。
